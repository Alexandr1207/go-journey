# Go Journey — дневник обучения Go

Учебный репозиторий по пути Python-разработчик → Junior Go Backend Developer.

## Прогресс

| День | Тема | Что сделано |
|---|---|---|
| [Week 1, Day 1](week01/day01-functions-errors) | Основы: функции, zero values, type inference | `divide()` с обработкой ошибки через `error`, проверка zero values (int/string/bool/float64), сравнение `var x int`/`var y`/`z :=` |
| [Week 1, Day 2](week01/day02-flowcontrol) | Flowcontrol: for, if, switch, defer | FizzBuzz через `switch`, короткая форма `if`, механика `defer` (LIFO), 3 варианта `for` (классический/while/бесконечный), проверка на простое число (`IsPrime`) |
| [Week 1, Day 3](week01/day03-slices-strings) | Слайсы, массивы, строки, range, мапы (базово) | `append` и его влияние на len/cap (в т.ч. случай, когда append выделяет новый массив и рвёт связь с исходным слайсом), `ReverseString` через `[]rune` (корректная работа с кириллицей), `CountWords` через мапу, матрица 3×3 через `[][]int`, эксперимент с `b := a` — разбор внутреннего устройства слайса (указатель+len+cap) и почему `b[0]=100` меняет оба слайса, а `append` иногда — нет |
| [Week 1, Day 4](week01/day04-pointers) | Указатели: `&`, `*`, pointer vs value receiver | `Increment` через `*int`, сравнение `modifyValue`/`modifyPointer`, метод `(c *Counter) Increment()` на структуре, `doubleAll` на слайсе, разбор receiver-синтаксиса |
| [Week 1, Day 5](week01/day05-maps) | Мапы углублённо: nil-мапы, `v, ok := m[key]`, delete во время range, вложенные мапы, мапа как множество | `SafeGet` через comma-ok идиому, `AverageGrade` по вложенной мапе (с оптимизацией прямого доступа вместо перебора), `HasDuplicates` через `map[int]struct{}`, `DeleteChildren` — удаление во время range (безопасно в Go по спецификации языка, в отличие от Python/Java), `CountWords`+`GetMax` — поиск самого частого слова |
| [Week 1, Day 6](week01/day06-practice) | Закрепление недели 1: типы, flowcontrol, строки, слайсы, мапы, указатели (10 задач на Codewars, 8→7 kyu) | `EachCons` (скользящее окно), `multipleOfIndex`, `Factorial`+`FactorialBig` (переход на `math/big` при переполнении `int` — разобран на примере 563!, числа Вильсона), `AmIWilson` (тест Вильсона, переписан под `big.Int` — `Cmp` вместо `==`, `Mul`/`Add` вместо операторов), `PowersOfTwo`, `Char` (ASCII), `MyString.IsUpperCase()` (первый самостоятельный метод на типе, до официальной темы недели 2), `Feast`, `DNAStrand`, `FindShort` (разобран баг с неверным стартовым значением), `SortByLength` |
| [Week 2, Day 1](week02/day01-structs) | Structs: создание, вложенные структуры, сравнение через `==`, указатель на структуру | `Book` (3 способа создания — именованные/позиционные/zero value), `Car`+`Engine` (вложенная структура), сравнение структур по значению через `==`, `FilterByYear`/`TotalPrice` на слайсе структур, `ApplyDiscount` через `*Book` — закрепление pointer vs value применительно к структурам |
| [Week 2, Day 2](week02/day02-methods) | Методы на структурах: pointer vs value receiver | `Book.Describe()` (value receiver, только чтение), `Book.ApplyDiscount()` (pointer receiver, изменение на месте), `Car.AddHorsepower()` (демонстрация разницы pointer/value на одном методе), `Book.WithDiscount()` (паттерн "билдер" — возврат новой структуры вместо мутации, разбор связи с иммутабельностью строк и функциональным стилем), собственная структура `Monitor` с обоими типами receiver |
| [Week 2, Day 3](week02/day03-interfaces) | Интерфейсы: неявная реализация, полиморфизм, type switch, ловушка nil-интерфейса | `Shape` (Circle/Rectangle, полиморфизм через `[]Shape`), `Descriable` (Book/Monitor реализуют один интерфейс без явного объявления связи), `PrintAll` с `type switch`, разбор классической Go-ловушки: интерфейс с nil-указателем внутри (`(*MyError, nil)`) не равен голому `nil` — типизированная пара (тип, значение) vs `(nil, nil)`, правильный паттерн — возвращать литерал `nil`, а не nil-переменную конкретного типа |
| [Week 2, Day 4](week02/day04-embedding) | Композиция вместо наследования: embedding структур и интерфейсов | `Dog`/`Cat` встраивают `Animal` (promotion методов), переопределение (`shadowing`) `Speak()` у Dog с явным вызовом родителя через `d.Animal.Speak()`, `Duck` с тройным embedding (Animal+Swimmer+Flyer), `ReadWriter` — embedding интерфейса в интерфейс, разбор ошибки: embedding интерфейса В СТРУКТУРУ (Student) — понята разница между "встроить интерфейс как поле-делегат" и "просто реализовать методы интерфейса напрямую" |
| [Week 2, Day 5](week02/day05-packages) | Пакеты и видимость: экспорт через регистр, приватные поля, конструкторы | Пакеты `library`+`shapes`, приватное поле `internalID` (недоступно снаружи пакета), конструктор `NewBook()` как единственный способ корректно его заполнить — разница в выводе `Book{}` напрямую vs через `NewBook()` |
| [Week 2, Day 6](week02/day06-practice) | Практика недели: мини-система "Зоопарк" + 5 задач Codewars (7 kyu) | Мини-система с полным набором паттернов недели — embedding (`Lion`/`Parrot` от `Animal`), полиморфизм через `Speaker` интерфейс, приватное поле `enclosureID` + конструкторы, `Feed`/`FilterByAge`; разбор багов `string(age)` вместо `strconv.Itoa` и лишнего receiver на конструкторе. Codewars: `Number` (пассажиры автобуса), `NbDig`/`ContainsDigit`, `BandNameGenerator`|
| [Week 3, Day 1](week03/day01-pointers-deep) | Указатели и память углублённо: `new` vs `make`, escape analysis, nil pointer dereference, `panic`/`defer`/`recover`, `**T` | Разбор `new([]int)` vs `make([]int, 0)` — почему `new` для слайса неудобен (возвращает `*[]int`), `go build -gcflags="-m"` — подтверждение escape to heap, `nilCounter` — паника на nil-указателе + перехват через `defer`+`recover()`, `doublePointer` — двойное разыменование `**pp += 10` |
| [Week 3, Day 2](week03/day02-slices-deep) | Слайсы под капотом: рост cap при append, утечка памяти через слайсинг больших массивов, three-index slicing, copy() | Наблюдение роста cap скачками (не линейно), `safeCopy` — защита от удержания гигантского backing array через `copy()` в новый слайс, `a[2:5]` vs `a[2:5:5]` — разница в поведении `append` (порча чужих данных через shared backing array vs гарантированная изоляция), `CloneSlice` — полностью независимая копия |
| [Week 3, Day 3](week03/day03-maps-final) | Мапы — закрытие темы: value receiver + мапа как поле, сравнение мап вручную, конкурентная небезопасность (анонс недели 4-5) | `Cache` с value receiver — демонстрация, почему мапа внутри структуры мутируется даже без pointer receiver, `MapsEqual` (с разбором edge case — нужен comma-ok, а не просто `a[key] != b[key]`), `GroupAnagrams` — классическая LeetCode-задача через сортировку рун как ключ мапы |
| [Week 3, Day 4](week03/day04-practice) | Закрепление недели 3: 5 задач на Codewars (6-7 kyu) | `Gimme` (поиск среднего элемента через `slices.Max`/`Min`), `FindNextSquare`, `Fib` (итеративная реализация без рекурсии), `Capitalize` (индексированная капитализация через `[]rune`), `RakeGarden` (трансформация слайса строк) |
| [Week 4, Day 1](week04/day01-goroutines) | Горутины: запуск через `go`, завершение main убивает горутины, недетерминированный порядок, гонка данных | `sayHello` + `Sleep` как костыль, 5 горутин в цикле (порядок меняется между запусками), передача `n` параметром vs замыкание на `i` (поведение до/после Go 1.22), 10 000 горутин с `counter++` без защиты (результат 9902 вместо 10000), `go run -race` — первый отчёт DATA RACE |
